# JvFunder

Static marketing site for JvFunder, the investor platform for Z-Co. Development projects. Files: `index.html`, `styles.css`, `app.js`, `legal.html`.

## Before launch
1. Replace pipeline/project copy with counsel-approved offering language.
2. Connect Investor Login to the selected secure investor-management / white-label provider.
3. Connect the interest forms to the CRM/email system.
4. Add real project renderings/photos. the Consumer Concepts card falls back to a gradient until its image is added; the dark Project Review section uses a Houston skyline photo.
5. Replace the `legal.html` placeholders with securities-counsel-approved Terms, Privacy and Risk disclosures.
6. Add analytics/cookie consent as required.
7. Do not accept securities subscriptions directly through this site unless the final regulatory/intermediary workflow permits it.
